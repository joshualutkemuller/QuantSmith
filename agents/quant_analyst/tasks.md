# Quant Analyst Tasks

## Route Quant Workflow

Input: research or production workflow request.

Output: recommended agent chain, assumptions, artifacts, validation gates, and
handoff path.

## Review Runnable Prototype

Input: code path, notebook, or package entry point plus intended use.

Output: review of correctness, reproducibility, leakage risk, missing tests, and
next implementation tasks.

## Promote Workflow To Spec

Input: approved workflow or handoff document.

Output: candidate `specs/NNNN-slug/` structure with initial requirements,
acceptance criteria, risks, and task outline.

## Package Runtime Handoff

Input: agent-local prototype code or scattered scripts.

Output: package placement recommendation, compatibility plan, entry points, and
smoke-test requirements.
