# Market Context Researcher Tasks

## Gather Context

Input: source policy, topic list, optional user material.

Output: context summary with source notes and caveats.

## Classify Claims

Input: source notes and context items.

Output: facts, reactions, inferences, speculation, jokes, and sourcing gaps.

## Prepare Ideation Brief

Input: classified context.

Output: compact brief for `quant_angle_generator` with source note IDs.
