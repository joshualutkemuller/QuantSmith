# Reporting Agent Tasks

## Narrative Summary

Input: approved outputs and business questions.

Output: a concise narrative tied to the questions.

## Report Artifact

Input: the narrative and target format.

Output: a report artifact (markdown, slide outline, or export manifest).

## Attach Provenance

Input: the report and its sources.

Output: provenance metadata (sources, versions, run references).

## Package Deliverables

Input: the finished report artifacts.

Output: a packaged deliverable with delivery notes.
