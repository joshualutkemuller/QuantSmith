# Universe Selection

## Purpose

Defines eligible assets, filters, liquidity screens, corporate-action handling,
survivorship controls, benchmark membership, and coverage gaps.

## Use When

- A portfolio needs a tradable universe before signal, risk, or optimization work.
- Existing universe logic may contain survivorship, stale-data, or investability bias.

## Inputs

- Mandate, benchmark, security master, prices, volumes, classifications,
  corporate actions, restrictions, liquidity data, and coverage reports.

## Outputs

- Universe definition, eligibility rules, exclusion reasons, point-in-time data
  requirements, risks, and test suggestions.

## Required Review Themes

- Investability, survivorship, corporate actions, liquidity, borrowability,
  classifications, stale identifiers, and benchmark alignment.
