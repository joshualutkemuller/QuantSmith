# Visual Playbook

Reusable visual concepts for the evening content workflow.

## Approved Patterns

| Pattern | Use When | Required Notes |
| --- | --- | --- |
| Effective breadth bar | Index concentration, factor crowding | Source weights, date, transformation |
| Flow waterfall | ETF, buyback, liquidity, funding narratives | Flow source, period, sign convention |
| Scatter with quadrant labels | Capex vs cash flow, valuation vs growth | Axis definitions, sample universe |
| Timeline | Policy, release calendar, market event sequence | Dates, source links, event labels |
| Before/after table | Rule changes, revisions, estimate updates | As-of dates and vintage caveat |

## Caveat Defaults

- Label illustrative visuals as illustrative.
- Label live-data visuals with source, retrieval time, and transformation.
- Avoid chart titles that state conclusions stronger than the data supports.
