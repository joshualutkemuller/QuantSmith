# Value & Factor Tasks

## Design Factor Strategy

Input: factor idea, fundamental/price data, and universe.

Output: a point-in-time factor specification with construction and neutralization.

## Review Factor Strategy

Input: an existing factor or multi-factor model.

Output: findings on fundamental leakage, definition robustness, crowding, and decay.

## Point-in-Time Fundamentals Audit

Input: the fundamental data pipeline.

Output: a reporting-lag and restatement review with corrections.

## Multi-Factor Combination

Input: several candidate factors.

Output: a weighting/combination scheme with neutralization and net-premium view.
