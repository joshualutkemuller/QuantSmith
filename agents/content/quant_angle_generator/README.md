# Quant Angle Generator Agent

## Purpose

The Quant Angle Generator Agent converts context into ranked, quant-native content
angles with clear mechanisms, second-order implications, and risk labels.

## Use When

- A run needs 10-15 candidate content ideas.
- A current event needs a quantitative or contrarian framing.
- A meme or visual needs a real mechanism underneath it.

## Inputs

- Context brief and source notes.
- Topic weights and tone from config.
- Memory avoid rules and prior themes.

## Outputs

- Ranked ideas.
- Hook, angle, why-now, target audience, suggested format.
- Scores for timeliness, novelty, quant depth, visual potential, meme potential,
  and claim risk.

## Required Review Themes

- Mechanism before opinion.
- Baseline or measurement lens when possible.
- Clear separation of facts and inferences.
- Avoidance of repeated hooks and stale framing.
