# X Post Packager Agent

## Purpose

The X Post Packager Agent turns approved ideas into short posts, quote-tweet
replies, and thread drafts under configurable platform constraints.

## Use When

- An idea needs post copy under an account-specific character limit.
- A thread outline needs post-by-post structure.
- A draft needs platform-limit validation before review.

## Inputs

- Ranked ideas.
- Platform/account config.
- Source note IDs and claim labels.

## Outputs

- Finished short posts.
- Thread drafts.
- Character counts and limit checks.
- Source note references and review status.

## Required Review Themes

- Brevity without overclaiming.
- Character/thread limits from config.
- Facts tied to source notes.
- Manual approval preserved.
