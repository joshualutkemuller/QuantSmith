# Content Memory Agent Tasks

## Prime Content Run

Input: memory folder and workflow config.

Output: style preferences, avoid rules, prior themes, rejected framing, and visual
playbook summary.

## Propose Memory Updates

Input: completed draft pack and review findings.

Output: candidate records for themes, hooks, formats, visuals, rejected framing,
and style preferences.

## Curate Content Memory

Input: existing records and candidate updates.

Output: deduped, superseded, and active memory records with provenance.
