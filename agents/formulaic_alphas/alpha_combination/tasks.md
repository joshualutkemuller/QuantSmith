# Alpha Combination Tasks

## Combine Alphas

Input: a set of alphas and their series.

Output: a correlation-aware weighting scheme and the combined book's characteristics.

## Spanning Test

Input: a new alpha and the existing book.

Output: a regression/spanning assessment of its incremental value.

## Correlation-Structure Review

Input: an alpha book.

Output: a pairwise-correlation and redundancy analysis with crowding flags.

## Weighting Robustness

Input: proposed alpha weights.

Output: an assessment of overfit risk and a more robust alternative.
