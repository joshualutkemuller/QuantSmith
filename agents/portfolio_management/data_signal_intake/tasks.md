# Data Signal Intake Tasks

## Inventory Inputs

Input: model outputs, data contracts, holdings, benchmarks, prices, risk inputs, and costs.

Output: input table with grain, as-of timing, owner, refresh cadence, and readiness.

## Review Signal Readiness

Input: forecast or alpha evidence.

Output: calibration, decay, confidence, leakage, benchmark, and fallback findings.

## Handoff To Allocation

Input: approved signal/risk/cost inputs.

Output: allocation-ready fields, missing values policy, and monitoring hooks.
