# Monitoring Governance Tasks

## Define Monitoring Plan

Input: mandate, specs, constraints, risk budgets, data contracts, model metrics, and owner map.

Output: metrics, thresholds, cadence, owners, escalation, and rollback policy.

## Triage Breach

Input: alert, run card, portfolio state, inputs, and limits.

Output: severity, likely cause, required action, owner, and evidence bundle.

## Review Operating Evidence

Input: recurring performance, risk, compliance, data, and model monitoring artifacts.

Output: keep/change/pause/retire recommendation and spec updates.
