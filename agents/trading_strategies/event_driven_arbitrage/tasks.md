# Event-Driven & Arbitrage Tasks

## Design Event Strategy

Input: an event type and its universe.

Output: a specification with point-in-time dating, payoff, and tail characterization.

## Review Event Strategy

Input: an existing event-driven/arbitrage strategy.

Output: findings on event dating, deal-break risk, sample size, and crowding.

## Deal-Break Risk Assessment

Input: a merger/risk-arb book.

Output: left-tail (deal-failure) characterization and sizing implications.

## Sample & Crowding Review

Input: the event history and universe.

Output: sample-adequacy and crowding assessment with capacity implications.
