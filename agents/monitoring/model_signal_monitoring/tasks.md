# Model & Signal Monitoring Tasks

## Monitor A Live Risk

Input: live vs reference measurements and thresholds.

Output: a health read with breaches and the observations for alerting.

## Declare Coverage

Input: a production risk.

Output: its metric, threshold/baseline, owner, alert, runbook, and review cadence.

## Review Monitoring

Input: an existing monitoring setup.

Output: gaps against the standard and concrete fixes.

## Hand Off To Alerting

Input: a set of observations.

Output: a handoff to `alerts/alert_policy` with suggested policies and severities.
