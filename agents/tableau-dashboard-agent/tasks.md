# Tableau Dashboard Agent Tasks

## Generate Dashboard Payload

Input: a dashboard request and prepared fields.

Output: a structured, schema-validated Tableau payload.

## Layout Recommendation

Input: the data and question.

Output: a layout recommendation drawn from retrieved dashboard patterns.

## Validate & Repair

Input: a draft payload.

Output: schema-validation results with bounded repairs applied.

## Deployment Notes

Input: a final payload.

Output: assumptions and deployment instructions.
