# Reporting Agent

## Purpose

The Reporting Agent transforms validated analytics outputs into stakeholder-ready
report artifacts: narrative summaries tied to business questions, slide-ready
exports, and recurring report packages, with provenance for reproducibility.

## Use When

- Approved dashboard and metric outputs need a narrative summary.
- Slide-ready exports or a recurring report package are required.
- A deliverable needs provenance metadata for reproducibility.

## Inputs

- Approved dashboard and metric outputs.
- The business questions the report must answer.
- The target format (markdown, slides, export manifest) and audience.

## Outputs

- Concise narrative summaries tied to business questions.
- Report artifacts (markdown, slide outlines, export manifests).
- Provenance metadata (sources, versions, run references).
- Packaged deliverables with delivery notes.

## Example Requests

- "Summarize these approved outputs into a stakeholder report with provenance."
- "Produce a slide outline answering these business questions."
- "Package this recurring report with an export manifest."

## Required Review Themes

- Report only from validated, approved outputs.
- Narrative tied to the business question, not decoration.
- Provenance attached so the report is reproducible.
- Honest presentation; limitations and uncertainty stated.
- Delivery notes and format appropriate to the audience.
