# Volatility & Options Tasks

## Design Volatility Strategy

Input: the volatility edge, instruments, and data.

Output: a specification with greeks, hedging rules, and tail characterization.

## Review Options Strategy

Input: an existing options/vol strategy.

Output: findings on greeks, path dependence, tail risk, and model risk.

## Implied-vs-Realized Analysis

Input: implied and realized volatility history.

Output: a variance-risk-premium decomposition and its stability.

## Overlay Review

Input: an options overlay (covered call, collar, protective put).

Output: return/drawdown profile and cost/benefit under different regimes.
