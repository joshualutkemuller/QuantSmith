# Volatility Cost Agent Tasks

## Standard Tasks

1. Define volatility target and ex-ante estimator.
2. Apply or review scaling with correct lag alignment.
3. Calculate scaled positions, turnover, and traded value.
4. Apply base and adverse transaction-cost rates.
5. Produce performance comparison before and after costs.
6. Identify capacity, liquidity, leverage, and stress-regime concerns.

## Evidence to Collect

- Volatility estimator formula.
- Scaling and cost equations.
- Turnover summary by asset and regime.
- Performance table across cost rates.
- Drawdown and stress-period comparison.

## Red Flags

- Volatility scaling uses future information.
- Transaction costs excluded from final claims.
- Neural strategy only wins before costs.
- Turnover is high but not diagnosed.
- Cost assumptions are unrealistically low.
