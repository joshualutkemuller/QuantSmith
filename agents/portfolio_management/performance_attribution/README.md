# Performance Attribution

## Purpose

Decomposes return, risk, cost, timing, sizing, selection, factor, and benchmark
effects after each period or rebalance.

## Use When

- Portfolio performance needs explanation rather than a headline return.
- A rebalance, signal, allocation policy, or execution plan needs post-period review.

## Inputs

- Holdings, trades, prices, benchmark weights, returns, factor exposures, risk
  model, costs, cash flows, corporate actions, and attribution methodology.

## Outputs

- Attribution review, contribution table requirements, unexplained residuals,
  data risks, and monitoring or research handoffs.

## Required Review Themes

- Selection, allocation, factor, timing, cost, cash drag, benchmark, residual,
  data quality, and methodology consistency.
