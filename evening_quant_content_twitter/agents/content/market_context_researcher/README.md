# Market Context Researcher Agent

## Purpose

The Market Context Researcher Agent gathers current market/news context and turns
it into source notes, fact/reaction/speculation labels, and context summaries for
content ideation.

## Use When

- A content run needs timely market context.
- User-supplied links, screenshots, or charts need source/context extraction.
- Claims need a first pass of source support before drafting.

## Inputs

- Source policy from config.
- User-supplied material.
- Web/API/market-data source notes when enabled.

## Outputs

- Context notes.
- Source notes.
- Fact, market reaction, inference, speculation, and caveat labels.
- Open sourcing gaps.

## Required Review Themes

- Source freshness.
- Release/vintage caveats for revised data.
- Public versus restricted information.
- Factual claims separated from narrative framing.
