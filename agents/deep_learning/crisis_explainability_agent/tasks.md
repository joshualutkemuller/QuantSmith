# Crisis Explainability Agent Tasks

## Standard Tasks

1. Define crisis, drawdown, and regime windows.
2. Compare model and baseline behavior within each window.
3. Separate raw allocation weights from scaled positions.
4. Attribute behavior to features, lags, volatility scaling, constraints, and costs.
5. Produce an economic interpretation and fragility assessment.
6. Define monitoring signals and review triggers.

## Evidence to Collect

- Crisis performance table.
- Weight and scaled-position time series.
- Feature sensitivity or attribution summary.
- Turnover and cost behavior during stress.
- Monitoring recommendations.

## Red Flags

- Crisis robustness claimed from aggregate metrics only.
- Attribution chart with no economic interpretation.
- Protective behavior caused only by ex-post scaling.
- Stress results that ignore liquidity or adverse costs.
