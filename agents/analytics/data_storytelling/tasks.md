# Data Storytelling Tasks

## Frame An Analysis As A Narrative

Input: a governed `Report` (`0010`), the audience, and the decision at stake.

Output: a narrative (key message, insight, recommended action, caveats) with the
provenance carried from the `Report`.

## Communicate An Experiment Result

Input: an experiment readout (`0009`).

Output: an audience-tailored summary that states the verdict and its caveats — a win
only when the experiment is powered, valid, and significant.

## Write A Dashboard Headline

Input: a dashboard's metrics and the target audience.

Output: a headline message and the "so what," handed to `dashboard_design` for the
visual story.

## Produce An Executive Summary

Input: a set of governed metrics and results.

Output: a short exec narrative with one key message and a recommended action, handed
to `reporting-agent` to render.
