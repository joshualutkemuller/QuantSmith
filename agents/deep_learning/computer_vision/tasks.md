# Computer Vision Tasks

## Classify Request

Input: a natural-language request, partial spec, prototype, or incident.

Output: problem classification, required inputs, adjacent agents, and whether a spec should be created or updated.

## Design Review

Input: candidate design, assumptions, constraints, model/solver choices, and expected outputs.

Output: review findings, missing requirements, risks, and acceptance criteria.

## Implementation Handoff

Input: approved design and repo context.

Output: build tasks, required tests, data contracts, run-card fields, and monitoring notes.

## Validation Review

Input: model/solver/backtest/experiment results.

Output: baseline comparison, failure modes, robustness checks, and go/no-go recommendation.
