# Quant Researcher Memory

Workflow-specific memory for the Quant Researcher workflow (see `docs/workflows.md`):
how this workflow uses each dataset — the patterns that worked and the decisions
made. Facts about the sources themselves live in `memory/_shared/`.

- Records are catalogued in `index.yaml`.
- Cross-dataset lessons are in `lessons.md`.
- Per-dataset usage is under `datasets/<ds>/`.

Reference example — copy the structure, not the content.
