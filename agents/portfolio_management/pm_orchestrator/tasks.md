# Portfolio Management Orchestrator Tasks

## Classify Request

Input: portfolio request, artifact, prototype, or incident.

Output: stage classification, required specialists, missing inputs, and spec need.

## Route Workflow

Input: classified request and available context.

Output: ordered handoff plan across PM, optimization, risk, data, testing, reporting, and monitoring agents.

## Review Handoff Completeness

Input: draft plan, tasks, or run card.

Output: gaps in ownership, approvals, rollback, monitoring, and acceptance criteria.
