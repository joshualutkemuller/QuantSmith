# PowerBI Dashboard Agent Tasks

## Generate Report Payload

Input: a report request and prepared fields.

Output: a structured, schema-validated Power BI payload.

## Governance Check

Input: a draft report.

Output: governance findings (naming, definitions, access) with fixes.

## Validate & Repair

Input: a draft payload.

Output: schema-validation results with bounded repairs applied.

## Deployment & Management Notes

Input: a final payload.

Output: assumptions and deployment/management instructions.
