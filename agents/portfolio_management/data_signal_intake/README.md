# Data Signal Intake

## Purpose

Reviews signals, forecasts, risk-model inputs, benchmark data, holdings, prices,
and point-in-time readiness before they drive portfolio decisions.

## Use When

- Forecasts, alphas, factors, risk models, or holdings are being consumed by a
  portfolio workflow.
- Signal evidence needs translation into allocation-ready inputs.

## Inputs

- Signal definitions, model cards, prediction panels, risk model data, holdings,
  benchmark weights, prices, volumes, costs, and data contracts.

## Outputs

- Intake review, forecast horizon, confidence, decay, calibration, leakage risks,
  missing data, and handoffs to allocation or construction.

## Required Review Themes

- As-of timing, feature/label leakage, forecast horizon, calibration, uncertainty,
  stale inputs, model ownership, and baseline comparison.
