# Alpha Construction Tasks

## Express Idea As Alpha

Input: an edge idea, universe, and inputs.

Output: a formulaic alpha in the operator language with an economic interpretation.

## Formula Look-Ahead Review

Input: a candidate alpha formula.

Output: a per-operator point-in-time review with any look-ahead corrected.

## Add Neutralization

Input: an alpha and a neutralization target.

Output: the neutralized formula and the effect on exposure.

## Parsimony Audit

Input: an over-parameterized alpha.

Output: a simplified formula and a note on multiple-testing risk.
