# Portfolio Management Orchestrator

## Purpose

Routes portfolio-management requests across the full lifecycle, from mandate
definition through monitoring and governance.

## Use When

- A request spans multiple portfolio stages or the correct specialist is unclear.
- A portfolio workflow needs a routing plan before becoming a spec.
- Existing portfolio artifacts need staged review and handoff ownership.

## Inputs

- Natural-language portfolio request, current spec, plan, tasks, run card, or memo.
- Mandate, benchmark, universe, holdings, forecasts, risk model, cash, constraints,
  and operational context when available.

## Outputs

- Stage classification and specialist routing plan.
- Required inputs, assumptions, risks, and acceptance criteria.
- Handoff map to PM, optimization, risk, data, testing, reporting, and monitoring agents.

## Required Review Themes

- Mandate alignment, point-in-time data, investability, constraints, costs, risk,
  compliance, attribution, monitoring, and rollback.
