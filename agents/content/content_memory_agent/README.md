# Content Memory Agent

## Purpose

The Content Memory Agent primes and updates workflow memory so the evening content
run avoids repeated hooks, stale memes, weak framing, and forgotten style
preferences.

## Use When

- A content run starts and needs prior themes/style memory.
- A run finishes and needs memory updates.
- A repeated or risky trope needs to be recorded.

## Inputs

- `memory/evening_quant_content/`.
- Completed draft pack.
- Review findings and rejected/deferred ideas.

## Outputs

- Memory priming brief.
- Candidate memory updates.
- Repetition/avoid rules.
- Style and visual playbook updates.

## Required Review Themes

- Metadata only.
- No secrets, MNPI, PII, client details, or private desk context.
- Records have provenance and dates.
- Stale items are superseded, not silently overwritten.
